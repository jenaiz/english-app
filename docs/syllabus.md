# Syllabus A1–C1

Cada nivel tiene **4 temas × 3 unidades = 12 unidades**. Cada unidad tiene una lección de 7 fases (contexto → descubrimiento → gramática → práctica → producción → vocabulario → repaso). Cada tema cierra con un **checkpoint** (lección `kind: "test"`). El nivel se certifica con un **examen de nivel** aparte de las unidades (`backend/data/exams/`): ver [levels/README.md](levels/README.md).

Referencias de organización (solo estructura y progresión, nunca se copia texto):
- **Cambridge English Grammar Profile** y **English Vocabulary Profile** ([englishprofile.org](https://www.englishprofile.org)): en qué nivel se espera cada estructura y palabra.
- **Core Inventory for General English** (British Council y EAQUALS): la lista pública de gramática de cada nivel. Es la referencia de los exámenes de nivel; la cobertura de cada nivel está en `levels/<nivel>.md`.
- Cursos de Cambridge (*Empower*) y Oxford (*English File*): unidades que combinan gramática, vocabulario, pronunciación y función comunicativa, con un repaso cada pocas unidades.

El contexto de todas las unidades es la historia de [story/bible.md](story/bible.md).
