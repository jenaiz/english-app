# Syllabus A1–C1

Cada nivel tiene **4 temas × 3 unidades = 12 unidades**. Cada unidad tiene una lección de 7 fases (contexto → descubrimiento → gramática → práctica → producción → vocabulario → repaso). Cada tema cierra con un **checkpoint** (lección `kind: "test"`), y la unidad 12 incluye además el **test de nivel**.

Referencias de organización (solo estructura y progresión, nunca se copia texto):
- **Cambridge English Grammar Profile** y **English Vocabulary Profile** ([englishprofile.org](https://www.englishprofile.org)): en qué nivel se espera cada estructura y palabra.
- Cursos de Cambridge (*Empower*) y Oxford (*English File*): unidades que combinan gramática, vocabulario, pronunciación y función comunicativa, con un repaso cada pocas unidades.

El contexto de todas las unidades es la historia de [story/bible.md](story/bible.md).

## C1 Advanced: *Her own studio* (borrador)

Temas: Farewells · Starting up · Pitching in New York · Looking back.
Gramática: inversión enfática; cleft sentences; participle clauses; hedging y lenguaje impersonal; nominalización; modales avanzados (*needn't have*, *might well*); colocaciones y registro formal frente a informal.
Integra `inversion_emphasis` (el discurso de despedida de Helen).
